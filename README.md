# Personal Recipe Organizer

A console-based Python application to organize recipes,
ingredients, preparation steps, and cooking information.

## Features

- Add new recipes
- View all recipes
- Search recipes by name or ingredient
- Filter recipes by category
- Update recipe details
- Delete recipes
- Store ingredients and preparation steps
- Track preparation and cooking time
- Generate recipe reports
- Save data in JSON format

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd Personal_Recipe_Organizer
```

Run the application:

```bash
python main.py
```
